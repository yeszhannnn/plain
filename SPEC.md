# Спецификация языка Plain

Редакция словаря: 2026. Документ описывает поведение компилятора `engc` в этом репозитории. Если документ и компилятор расходятся, это ошибка, о ней нужно сообщить.

## 1. Исходный файл

- Расширение `.eng`, кодировка UTF-8.
- Регистр букв в словах не важен: `Say`, `say` и `SAY` одинаковы. Текст в кавычках сохраняет регистр.
- Отступы ни на что не влияют.
- Комментариев в языке пока нет.

### 1.1 Предложения

Программа состоит из предложений. Предложение заканчивается:
- точкой;
- концом строки;
- двоеточием, после которого начинается тело на той же строке (`repeat 5 times: say hi`).

Точка между двумя цифрами не завершает предложение, но дробные числа не поддерживаются (раздел 3.1). Точки, двоеточия и запятые внутри кавычек относятся к тексту.

Пустая строка закрывает самую внутреннюю открытую группу (раздел 5.2), если в ней уже есть хотя бы одно предложение.

### 1.2 Текст в кавычках

Текст берётся в двойные `"…"` или одинарные `'…'` кавычки. Типографские кавычки `“ ” ‘ ’` равнозначны обычным. Апостроф между двумя буквами (`don't`, `user's`) считается частью слова, а не кавычкой.

### 1.3 Нормализация

До разбора компилятор механически упрощает предложение. Правила применяются в таком порядке:

1. Сокращения раскрываются: `that's` → `that is`, `it's` → `it is`, `isn't` → `is not`, `what's` → `what is`, `doesn't` → `does not`.
2. Числа словами превращаются в числа (раздел 3.1).
3. Притяжательная форма `X's Y` становится одним именем `X's Y` (раздел 4.1).
4. Удаляются артикли `the`, `a`, `an` и слова вежливости `please`, `just`, `kindly`. Поэтому `a`, `an` и `the` нельзя использовать как имена.
5. Слова-ярлыки `word`, `words`, `text`, `number`, `value`, `phrase` удаляются, если за ними идёт текст в кавычках или число (`say the number 5`), а также если они стоят сразу после глагола печати или ответа перед словом (`print the word hello`).
6. Синонимы заменяются каноническими ключевыми словами по словарю `lexicon.json`. Побеждает самая длинная подходящая фраза: `is greater than or equal to` распознаётся раньше, чем `is greater than`.
7. `their X` становится именем переменной пользователя (раздел 7.4).

## 2. Типы

| Тип | Как появляется | Как печатается |
|---|---|---|
| число | `18`, `five`, арифметика | `18` |
| текст | `"hello"`, одно незнакомое слово, `the message` | как есть |
| да/нет | результат условия | `true` / `false` |

- Целые числа 64-битные со знаком.
- Объявлять типы не нужно, компилятор выводит их сам.
- Переменная хранит значения одного типа. Если `age` получила число, присвоить ей текст нельзя: это ошибка компиляции с номерами обеих строк.
- Неявных преобразований нет: `"5" plus 1` даёт ошибку.
- Значения «да/нет» существуют только внутри условий, сохранить их в переменную пока нельзя.

## 3. Значения

### 3.1 Числа

- Цифрами: `0`, `42`, `-7` (минус перед числом записывается символом).
- Словами: `zero` … `nineteen`, `twenty` … `ninety`, `hundred`, `thousand` и их сочетания: `twenty-one`, `twenty one`, `one hundred and five`, `two thousand`.
- `once`, `twice`, `thrice` означают `1 times`, `2 times`, `3 times`.
- Исключение: `one of` не превращается в число (раздел 3.5).
- Дробных чисел нет: `18.5` даёт ошибку.

### 3.2 Текст

- В кавычках: `"Hello, world"`.
- Одно слово без кавычек: если переменной с таким именем нет, это текст с исходным написанием (`say Hello` печатает `Hello`). Если переменная есть, берётся её значение.
- Текст из нескольких слов обязательно берётся в кавычки.
- Служебные слова языка (`done`, `end`, `it`, `times`, `message` и другие из `lexicon.json`) без кавычек текстом не считаются: `say done` даёт ошибку, а `say "done"` работает.

### 3.3 Арифметика

| Операция | Словами | Символом |
|---|---|---|
| сложение | `plus` | `+` |
| вычитание | `minus`, `take away` | `-` |
| умножение | `times`, `multiplied by` | `*`, `×` |
| деление | `divided by` | `/` |
| остаток | `mod`, `modulo`, `the remainder of A divided by B` | `%` |

- Деление целочисленное, результат округляется к нулю: `7 / 2` = 3, `-7 / 2` = -3.
- Остаток имеет знак делимого: `-7 mod 2` = -1.
- Деление на ноль останавливает программу.
- Круглые скобки группируют выражения.

Приоритет операций:
- символы подчиняются школьным правилам: `1 + 2 * 3` = 7;
- словесные операции одной силы читаются слева направо: `10 minus 3 minus 2` = 5;
- словесные операции разной силы без скобок дают ошибку неоднозначности: `1 plus 2 times 3` можно понять двумя способами, поэтому компилятор просит поставить скобки;
- если в паре операций хотя бы одна записана символом, действуют школьные правила.

### 3.4 Случайное число

```text
a random number from 1 to 6
a random number between 1 and 100
```

Оба конца включаются. Если первое число больше второго, они меняются местами. Концами могут быть числа или переменные.

### 3.5 Случайный выбор

```text
one of "yes", "no" and "maybe"
```

Варианты разделяются запятыми, `and` или `or`. Нужно не меньше двух вариантов, и все они должны быть одного типа.

### 3.6 `it`

`it` означает последнюю переменную, которой выше по тексту что-то присвоили или которую изменили. Значение `it` определяется при компиляции по порядку предложений, а не во время выполнения.

```text
set x to 4. double it. say it.     → 8
```

## 4. Переменные

### 4.1 Имена

Имя переменной — одно слово (`age`, `score`, `r3`) или притяжательная пара (`the user's score`, хранится как одно имя). `their X` — переменная пользователя, она существует только в ботах (раздел 7.4).

### 4.2 Присваивание

```text
set age to 18.
let age be 18.
make age be 18.
age is 18.
the user's score is 100.
```

Форма `X is …` работает, только если имя стоит в начале предложения. После `if`, `until`, `when` слово `is` означает сравнение.

Значение можно склеить из частей через `and then` или `followed by`, по тем же правилам пробелов, что и при печати (раздел 5.1). Результат всегда текст:

```text
set greeting to "Hi" and then name and then "!".
set report to report and then a new line and then score.
```

`a new line` (также `line break`, `newline`) — текст из одного перевода строки. Так собираются многострочные ответы ботов.

### 4.3 Изменение чисел

```text
add 5 to score.            subtract 2 from score.
increase score by 5.       decrease score by 2.
increase score.            decrease score.          (на 1)
double score.              halve score.             (halve делит нацело)
```

Если переменной ещё нет, эти команды создают её со значением 0. Поэтому счётчики можно не объявлять.

### 4.4 Начальные значения

Все переменные заполняются нулём своего типа: числа — `0`, текст — пустая строка.

Переменная появляется в том месте текста, где ей впервые что-то присвоили. Выше этого места её имя ещё не известно:
- одно слово в таком случае считается текстом: `say score.` до `set score to …` печатает `score`;
- притяжательное имя даёт ошибку: `I don't know "user's score" yet.`

## 5. Команды

### 5.1 Печать

```text
say "Hello".
print the word 'Hello' 5 times.
show "score is" and then score.
```

Глаголы: `print`, `show`, `say`, `display`, `output`, `write`, `tell`, `echo`, `announce` и их формы на `-s` и `-ing`.

Части соединяются через `and then` или `followed by` и печатаются в одну строку. Между частями ставится один пробел, кроме трёх случаев:
- предыдущая часть заканчивается пробелом;
- следующая часть начинается с пробела;
- следующая часть начинается со знака `. , ! ? ; : )`.

```text
say "Hi" and then name and then "!".     → Hi Ana!
```

`N times` в конце предложения повторяет печать N раз. `times` между двумя значениями означает умножение:

```text
say 2 times 3 4 times.     → 6, напечатано четыре раза
```

### 5.2 Группы

Группа — несколько предложений, которые относятся к одной команде. Группу открывают:
- `do the following N times`, `repeat N times`, `repeat the following N times`;
- `if <условие>` без запятой;
- `otherwise` без продолжения;
- `when someone sends …` без запятой (раздел 7).

Группу закрывают `that's all`, `that's it`, `done`, `end` или пустая строка.

```text
do the following three times.
  say "still here".
  add one to the counter.
that's all.
```

Если после заголовка стоит двоеточие и текст на той же строке, тело — это одно предложение:

```text
repeat 5 times: show 'Hello'
```

### 5.3 Повторение

```text
say hi 3 times.
repeat 3 times say hi.
repeat 3 times: say hi
do the following 3 times. … that's all.
```

Количество повторений вычисляется один раз перед началом. Отрицательное число или ноль означает «ни разу».

### 5.4 Условия

```text
if score is more than 50, say "well done".
if score is more than 50 then say "well done".
otherwise say "try again".

if score is more than 50
  say "well done".
  add 1 to level.
otherwise
  say "try again".
that's all.

otherwise, if score is more than 20, say "not bad".
```

`otherwise` относится к ближайшему предыдущему `if` без `otherwise` в той же группе, в том числе к последнему звену цепочки `otherwise, if`.

У звена `otherwise, if <условие>` без запятой после условия тело идёт группой на следующих строках:

```text
if mode is "a", say "first".
otherwise, if mode is "b"
  say "second".
  add 1 to seen.
that's all.
otherwise say "something else".
```

Условие в конце предложения относится ко всему предложению:

```text
say "yay" twice, but only if the user is happy.
say "hi" if count is 0.
```

Слова для такого условия: `if`, `when`, `only if`, `but only if`, `but if`, `provided that`, `provided`.

### 5.5 Цикл «пока»

```text
keep doubling the number until it is bigger than 100.
keep halving n while n is more than 1.
```

Тело — одна простая команда (печать, присваивание или изменение числа). Условие проверяется перед каждым шагом, поэтому если оно сразу выполнено (`until`) или сразу ложно (`while`), команда не выполнится ни разу.

## 6. Сравнения

| Смысл | Формы |
|---|---|
| равно | `is`, `equals`, `is equal to`, `=` |
| не равно | `is not`, `isn't`, `does not equal`, `is different from`, `!=` |
| больше | `is more than`, `is greater than`, `is bigger than`, `is larger than`, `is higher than`, `is above`, `is over`, `exceeds`, `>` |
| меньше | `is less than`, `is smaller than`, `is fewer than`, `is lower than`, `is below`, `is under`, `<` |
| не меньше | `is at least`, `is not less than`, `>=` |
| не больше | `is at most`, `is not more than`, `<=` |
| содержит | `contains`, `includes` |
| начинается с | `starts with`, `begins with` |

- Сравнивать можно только значения одного типа.
- Больше и меньше бывают только числа.
- `is` для текста сравнивает точно, с учётом регистра: `"Hi" is "hi"` ложно.
- `contains` и `starts with` работают только с текстом и не учитывают регистр латинских букв.
- Условия объединяются через `and`, `or` и `not`. `and` связывает сильнее, чем `or`. Внутри одного условия `and` всегда означает логическое «и».

## 7. Telegram-боты

Программа становится ботом, если в ней есть хотя бы одно правило `when someone sends …`.

### 7.1 Порядок выполнения

1. Предложения вне правил выполняются один раз при запуске, сверху вниз.
2. Бот получает сообщения через long polling.
3. Для каждого текстового сообщения правила проверяются сверху вниз. Выполняется первое подходящее, остальные пропускаются.
4. Если не подошло ни одно правило, бот молчит.

Сообщения без текста (фото, стикеры, голосовые) пропускаются.

### 7.2 Правила

Начало правила: `when someone sends`, а также `when somebody sends`, `when anyone sends`, `when someone writes`, `when someone types`, `when someone says`, `when someone presses`, `when user sends`, `when they send`, `if someone sends`.

| Запись | Срабатывает, когда сообщение… |
|---|---|
| `when someone sends "/start"` | совпадает с текстом без учёта регистра и пробелов по краям |
| `when someone sends "hi", "hello" or "hey"` | совпадает с любым из вариантов |
| `when someone sends a number` | целиком является целым числом (до 18 цифр, можно со знаком) |
| `when someone sends a message that contains "price"` | содержит текст без учёта регистра (также `containing`, `includes`) |
| `when someone sends a message that starts with "/buy"` | начинается с текста |
| `when someone sends anything` | любое (также `anything else`, `something`, `a message`) |

После условия правила идёт либо запятая и одно предложение, либо группа до `that's all`. Правило не может находиться внутри другой группы.

Сравнение без учёта регистра пока работает только для латиницы: `"Кофе"` и `"кофе"` — разные тексты.

### 7.3 Сообщение и отправитель

| Выражение | Тип | Значение |
|---|---|---|
| `the message`, `their message`, `what they sent` | текст | текст сообщения |
| `their name`, `their first name` | текст | имя отправителя из профиля Telegram |
| `the number they sent` | число | сообщение как число, или 0, если это не число |

Эти выражения, команда `reply` и переменные `their …` разрешены только внутри правил.

### 7.4 Память

- Переменные с `their` (`their score`, `their tries`) хранятся отдельно для каждого чата. У нового пользователя они равны нулю своего типа.
- Переменные без `their` общие для всех пользователей.
- Вся память живёт, пока работает процесс бота. После перезапуска она пустая.

### 7.5 Ответ

```text
reply "Thanks!".
reply "Hi" and then their name and then "!".
reply "Pick one" with buttons "Yes", "No" and "Maybe".
```

Глаголы: `reply`, `answer`, `respond`, `reply with`, `answer with`, `respond with`, `send back`. Части соединяются по правилам печати (раздел 5.1).

Кнопки задаются через `with buttons`, `with button`, `with options` или `with choices` и показываются как клавиатура под полем ввода, по три в ряд. Нажатие кнопки приходит боту как обычное сообщение с текстом кнопки, поэтому его ловит обычное правило:

```text
when someone sends "Yes", reply "Great!".
```

Подписи кнопок должны быть текстом. Ответ без кнопок оставляет клавиатуру, которая уже была показана.

### 7.6 Переменные окружения

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather, обязательна |
| `TELEGRAM_API_URL` | адрес Bot API, по умолчанию `https://api.telegram.org`; для тестов и своего сервера |
| `PLAIN_BOT_EXIT_WHEN_IDLE` | если задана, бот завершается, когда новых сообщений нет; используется в тестах |

Если Telegram отклонил запрос (например, из-за неверного токена), бот печатает причину и завершается с кодом 1. При ошибке сети он ждёт 3 секунды и пробует снова.

## 8. Ошибки компиляции

Программа с ошибкой не запускается. Сообщения пишутся по-английски, с номером строки.

| Ситуация | Пример сообщения |
|---|---|
| неизвестное слово | `I don't know the word "prnit". Did you mean "print"?` |
| два прочтения | `This sentence can mean 2 different things: …` |
| смена типа | `"age" was a number on line 1, and here it would become text.` |
| имя ещё не задано | `I don't know "user's score" yet. Set it first, for example: set user's score to 0.` |
| бот вне правила | `"reply" only exists inside a "when someone sends ..." rule.` |
| незакрытая кавычка | `A quote is opened but never closed.` |

Компилятор никогда не выбирает одно из нескольких прочтений сам. Если фраза понимается двумя способами, это ошибка, и в сообщении перечислены оба варианта.

## 9. Словарь

Все синонимы перечислены в `lexicon.json`. Словарь заморожен внутри редакции: в редакции 2026 значение фраз не меняется. Новые синонимы появляются только в следующей редакции.

## 10. Чего пока нет

- дробных чисел;
- списков и цикла `for every`;
- собственных команд и функций;
- ввода с клавиатуры в консольных программах;
- сохранения памяти бота на диск;
- inline-кнопок под сообщением и рассылки всем пользователям;
- комментариев.
