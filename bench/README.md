# Скорость

Один и тот же алгоритм (решето Эратосфена, простые числа до 5 000 000) на трёх языках: `primes.eng`, `primes.py`, `primes.c`.

```bash
python3 engc.py build bench/primes.eng -o primes_plain
clang -O2 bench/primes.c -o primes_c
time ./primes_plain
time ./primes_c
time python3 bench/primes.py
```

Замер в облачном контейнере (clang 18, Python 3.13), лучшее из пяти запусков:

| Версия | Время |
|---|---|
| C, `clang -O2` | 0.03 с |
| Plain, нативный бинарник | 0.18 с |
| Python 3.13 | 1.67 с |

Plain здесь примерно в 9 раз быстрее Python и примерно в 6 раз медленнее C. Разница с C: каждый элемент списка в Plain занимает 8 байт и проверяется на выход за границы, а в программе на C используется массив байтов без проверок. Первый запуск после сборки обычно медленнее остальных.
